# Game Development Portfolio

This project is a simple game development portfolio website that showcases video content related to game development. Below are the details on how to set up and run the website.

## Project Structure

```
game-portfolio
├── src
│   ├── index.html          # Main HTML document for the portfolio website
│   ├── styles
│   │   └── style.css       # CSS styles for the portfolio website
│   ├── scripts
│   │   └── main.js         # JavaScript code for interactivity
│   └── assets
│       └── videos
│           └── [your-video-file].mp4  # Video content placeholder
├── README.md               # Project documentation
```

## Getting Started

1. **Clone the Repository**
   ```bash
   git clone [repository-url]
   cd game-portfolio
   ```

2. **Open the Project**
   Open the `src/index.html` file in your web browser to view the portfolio.

3. **Video Content**
   Replace `[your-video-file]` in the `src/assets/videos/` directory with your actual video file name to display your game development videos.
